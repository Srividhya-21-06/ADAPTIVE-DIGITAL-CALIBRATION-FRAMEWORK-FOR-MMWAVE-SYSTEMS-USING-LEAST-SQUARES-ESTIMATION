# 📡 Adaptive Digital Calibration Framework for mmWave Systems Using Least Squares Estimation

## 📌 Project Overview

The Adaptive Digital Calibration Framework for mmWave Systems Using Least Squares Estimation is a MATLAB-based project developed to improve the accuracy, reliability, and performance of millimeter-wave (mmWave) communication systems. The project focuses on minimizing calibration errors and compensating for signal distortions caused by hardware imperfections and high-frequency communication challenges.

The framework uses the Least Squares Estimation (LSE) technique to estimate and reduce system errors adaptively. By continuously analyzing the signal characteristics, the system improves calibration efficiency and enhances communication stability in advanced wireless communication systems.

# ⚙️ Working Principle

### Step 1 — Signal Generation

The mmWave communication signal is generated and processed within the MATLAB environment.

### Step 2 — Error Introduction

System imperfections such as noise, phase mismatch, and calibration errors are introduced into the communication model.

### Step 3 — Least Squares Estimation

The Least Squares Estimation algorithm estimates unknown error parameters by minimizing the squared estimation error.

### Step 4 — Adaptive Calibration

The framework adaptively compensates for the estimated errors and improves signal quality.

### Step 5 — Performance Analysis

The corrected signal output and calibration performance are analyzed using graphs and simulation results.
